# Быстрый Старт

Это руководство позволит вам перейти от нуля к полностью автоматизированному резервному копированию истории браузера **менее чем за пять минут**.

---

## Шаг 1 — Первый Запуск

Запустите HistorySync. При первом запуске **Мастер настройки** проведёт вас через основные параметры.

Если вы установили из исходного кода:
```bash
python -m src.main
```

---

## Шаг 2 — Синхронизация Браузеров

На **Панели управления** нажмите **Синхронизировать сейчас**. HistorySync выполнит:

1. Автоматическое обнаружение всех установленных браузеров в системе.
2. Безопасное чтение их SQLite-баз данных истории с использованием снимков WAL — браузеры могут оставаться открытыми.
3. Импорт записей в локальную базу данных HistorySync.

!!! tip "Первая синхронизация занимает больше времени"
    Если у вас многолетняя история из нескольких браузеров, первая синхронизация может занять одну-две минуты. Последующие синхронизации **инкрементальные** — импортируются только новые записи.

### Выборочная синхронизация

Для синхронизации только конкретных браузеров используйте CLI:
```bash
hsync -s --browsers chrome,firefox
```

---

## Шаг 3 — Поиск в Истории

### Поиск в GUI
Используйте строку поиска в верхней части вкладки **История**. По мере ввода результаты появляются мгновенно.

### Глобальное Наложение (Spotlight)
Нажмите <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> из **любого приложения**, чтобы открыть наложение быстрого доступа. Работает на Windows, macOS и Linux (X11). В среде Wayland привяжите `python -m src.main --quick` к системному сочетанию клавиш.

Вводите текст естественно или используйте [Расширенный DSL Запросов](cli-reference.md#query-dsl):

| Пример запроса | Что он находит |
|---|---|
| `python async` | Страницы с этими словами в заголовке или URL |
| `domain:github.com` | Только страницы GitHub |
| `after:2024-06-01 domain:arxiv.org` | Статьи, прочитанные после июня 2024 |
| `is:bookmarked tag:work` | Страницы, добавленные в закладки с тегом «work» |
| `react -tutorial` | Страницы о React, исключая туториалы |

---

## Шаг 4 — Включение Автоматической Синхронизации

Перейдите в **Настройки → Автосинхронизация** и:

1. Включите **Автосинхронизацию**.
2. Установите предпочтительный интервал (по умолчанию: 2 часа).
3. Включите **Запуск при старте системы**, чтобы HistorySync запускался в фоне автоматически.

Теперь история браузера непрерывно объединяется в единую базу данных с возможностью поиска — автоматически.

---

## Шаг 5 — Настройка Облачного Резервного Копирования (Необязательно)

Резервное копирование через WebDAV позволяет восстановить историю на новом компьютере или синхронизировать её между устройствами.

1. Перейдите в **Настройки → Облачное резервное копирование WebDAV**.
2. Введите URL вашего WebDAV-сервера, имя пользователя и пароль.
3. Включите **Автоматическое резервное копирование** и установите интервал.
4. Нажмите **Проверить соединение** для проверки.

Посмотрите [руководство по настройке WebDAV](webdav-setup.md) для получения списка совместимых провайдеров с пошаговыми инструкциями.

---

## Шаг 6 — Режим Трея (Работа в Фоне)

После настройки закройте главное окно. HistorySync свернётся в **системный трей** и продолжит синхронизацию и резервное копирование в фоне.

Щёлкните правой кнопкой мыши на значке трея, чтобы:

- **Открыть HistorySync** — вернуть главное окно.
- **Синхронизировать сейчас** — запустить немедленную синхронизацию.
- **Резервная копия сейчас** — запустить немедленное WebDAV-резервное копирование.
- **Выйти** — полностью остановить приложение.
