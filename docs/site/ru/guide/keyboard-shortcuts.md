# Сочетания Клавиш

HistorySync предоставляет **25 настраиваемых сочетания** — одну глобальную горячую клавишу и 24 привязки внутри приложения. Все они могут быть изменены в **Настройки → Сочетания клавиш**.

---

## Глобальное Сочетание

Это сочетание работает на уровне системы — оно срабатывает даже когда HistorySync находится в фоне или свёрнут в трей.

| Действие | По умолч. | Примечания |
|---|---|---|
| **Открыть Наложение Быстрого Доступа** | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Показывает / скрывает поисковое наложение в стиле Spotlight |

!!! info "Linux / Wayland"
    Глобальные сочетания через `pynput` **не поддерживаются на Wayland**. Используйте `--quick` с системным сочетанием клавиш в качестве обходного решения:
    ```bash
    # Привяжите эту команду к системному сочетанию в настройках вашего DE
    python -m src.main --quick
    ```

!!! info "macOS"
    При первом срабатывании глобального сочетания macOS запросит разрешение **Специальные возможности**. Предоставьте его в **Системных настройках → Конфиденциальность и безопасность → Специальные возможности**.

---

## Сочетания Внутри Приложения

Эти сочетания активны, когда окно HistorySync находится в фокусе.

### Текущие значения по умолчанию

| Категория | Сочетания по умолчанию |
|---|---|
| **Навигация по страницам** | Панель управления <kbd>Ctrl</kbd>+<kbd>1</kbd>, История <kbd>Ctrl</kbd>+<kbd>2</kbd>, Закладки <kbd>Ctrl</kbd>+<kbd>3</kbd>, Настройки <kbd>Ctrl</kbd>+<kbd>4</kbd>, Журналы <kbd>Ctrl</kbd>+<kbd>5</kbd>, Статистика <kbd>Ctrl</kbd>+<kbd>6</kbd> |
| **Глобальные действия** | Синхронизировать сейчас <kbd>Ctrl</kbd>+<kbd>R</kbd>, Фокус на поиске <kbd>Ctrl</kbd>+<kbd>F</kbd> |
| **Страница истории** | Открыть выбранное <kbd>Enter</kbd>, Удалить выбранное <kbd>Delete</kbd>, Копировать URL <kbd>Ctrl</kbd>+<kbd>C</kbd>, Копировать заголовок + URL <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>, Переключить закладку <kbd>Ctrl</kbd>+<kbd>B</kbd>, Добавить заметку <kbd>Ctrl</kbd>+<kbd>N</kbd>, Открыть экспорт <kbd>Ctrl</kbd>+<kbd>E</kbd>, Скрытие выбранного не назначено по умолчанию |
| **Страница закладок** | Открыть <kbd>Enter</kbd>, Копировать URL <kbd>Ctrl</kbd>+<kbd>C</kbd>, Удалить <kbd>Delete</kbd>, Добавить заметку <kbd>Ctrl</kbd>+<kbd>N</kbd>, Найти в истории <kbd>Ctrl</kbd>+<kbd>L</kbd> |
| **Страница статистики** | Предыдущий период <kbd>Alt</kbd>+<kbd>Left</kbd>, Следующий период <kbd>Alt</kbd>+<kbd>Right</kbd> |
| **Страница настроек** | Сохранить <kbd>Ctrl</kbd>+<kbd>S</kbd> |

Диалог настроек остаётся источником истины. Пустые сочетания намеренно не назначены по умолчанию.

## Настройка Сочетаний

1. Перейдите в **Настройки → Сочетания клавиш**.
2. Нажмите на сочетание, которое хотите изменить.
3. Нажмите новую комбинацию клавиш.
4. Нажмите **Сохранить**.

Чтобы **отключить** сочетание, нажмите на него и нажмите <kbd>Backspace</kbd> или <kbd>Delete</kbd> для очистки.

!!! warning "Конфликты"
    Если два действия используют одну и ту же комбинацию клавиш, приоритет имеет последнее установленное. В диалоге настроек будет показан значок предупреждения для конфликтующих сочетаний.

## Сочетания в Наложении Быстрого Доступа

Эти сочетания работают внутри наложения (панель `Ctrl+Shift+H`):

| Действие | Клавиша |
|---|---|
| **Навигация по результатам** | <kbd>↑</kbd> / <kbd>↓</kbd> |
| **Открыть выбранный URL** | <kbd>Enter</kbd> |
| **Открыть в новой вкладке** (если браузер поддерживает) | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> |
| **Закрыть наложение** | <kbd>Esc</kbd> |
| **Очистить поиск** | <kbd>Ctrl</kbd>+<kbd>A</kbd>, затем <kbd>Delete</kbd> |
