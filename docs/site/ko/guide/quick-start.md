# 빠른 시작

이 가이드는 **5분 안에** 브라우저 기록 자동 백업을 완전히 구성하는 방법을 안내합니다.

---

## 1단계 — 첫 실행

HistorySync를 시작합니다. 첫 실행 시 **설정 마법사**가 핵심 설정을 안내합니다.

소스에서 설치한 경우:
```bash
python -m src.main
```

---

## 2단계 — 브라우저 동기화

**대시보드**에서 **지금 동기화**를 클릭합니다. HistorySync가 다음을 수행합니다:

1. 시스템에 설치된 모든 브라우저를 자동으로 감지합니다.
2. WAL 스냅샷을 사용하여 SQLite 기록 데이터베이스를 안전하게 읽습니다 — 브라우저가 열려 있어도 충돌이 없습니다.
3. 레코드를 로컬 HistorySync 데이터베이스로 가져옵니다.

!!! tip "첫 번째 동기화는 시간이 걸립니다"
    여러 브라우저에 수년치 기록이 있다면 첫 번째 동기화에 1~2분 정도 소요될 수 있습니다. 이후 동기화는 **증분 방식**으로 — 새로운 레코드만 가져옵니다.

### 선택적 동기화

특정 브라우저만 동기화하려면 CLI를 사용하세요:
```bash
hsync -s --browsers chrome,firefox
```

---

## 3단계 — 기록 검색

### GUI 검색
**기록** 탭 상단의 검색 창을 사용하세요. 입력하는 즉시 결과가 나타납니다.

### 전역 오버레이 (스포트라이트)
**어떤 애플리케이션에서든** <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd>를 눌러 빠른 접근 오버레이를 호출합니다. Windows, macOS, Linux(X11)에서 작동합니다. Wayland 환경에서는 `python -m src.main --quick`을 시스템 단축키에 바인딩하세요.

자연스럽게 입력하거나 [고급 쿼리 DSL](cli-reference.md#query-dsl)을 사용하세요:

| 쿼리 예시 | 검색 내용 |
|---|---|
| `python async` | 제목이나 URL에 해당 단어가 포함된 페이지 |
| `domain:github.com` | GitHub 페이지만 |
| `after:2024-06-01 domain:arxiv.org` | 2024년 6월 이후에 읽은 논문 |
| `is:bookmarked tag:work` | "work" 태그가 붙은 북마크된 페이지 |
| `react -tutorial` | 튜토리얼을 제외한 React 관련 페이지 |

## 4단계 — 자동 동기화 활성화

**설정 → 자동 동기화**로 이동하여:

1. **자동 동기화**를 활성화합니다.
2. 원하는 간격을 설정합니다 (기본값: 2시간).
3. **시스템 시작 시 실행**을 활성화하면 HistorySync가 백그라운드에서 자동으로 시작됩니다.

이제부터 브라우저 기록이 하나의 검색 가능한 데이터베이스로 자동으로 통합됩니다.

---

## 5단계 — 클라우드 백업 설정 (선택 사항)

WebDAV 백업을 사용하면 새 기기에서 기록을 복원하거나 여러 기기 간에 공유할 수 있습니다.

1. **설정 → WebDAV 클라우드 백업**으로 이동합니다.
2. WebDAV 서버 URL, 사용자명, 비밀번호를 입력합니다.
3. **자동 백업**을 활성화하고 간격을 설정합니다.
4. **연결 테스트**를 클릭하여 확인합니다.

호환되는 제공업체 목록과 단계별 안내는 [WebDAV 설정 가이드](webdav-setup.md)를 참조하세요.

---

## 6단계 — 트레이 모드 (백그라운드 실행)

설정이 완료되면 메인 창을 닫습니다. HistorySync가 **시스템 트레이**로 최소화되어 조용히 동기화와 백업을 계속합니다.

트레이 아이콘을 오른쪽 클릭하면:

- **HistorySync 열기** — 메인 창을 다시 불러옵니다.
- **지금 동기화** — 즉시 동기화를 실행합니다.
- **지금 백업** — 즉시 WebDAV 백업을 실행합니다.
- **종료** — 애플리케이션을 완전히 종료합니다.
