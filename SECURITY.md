# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of HistorySync.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

If you discover a security issue, report it privately by email:

0x4fe6@gmail.com

Include:
- A description of the issue
- Steps to reproduce
- Potential impact

We aim to respond within 72 hours and will coordinate disclosure and a fix timeline.
